# 定价草案（Draft）

> 非正式报价单。用于内部对齐与试点报价；上线前按 LLM/带宽 COGS 再校准。

## 计费单元

- **按店铺（Shop）订阅**，一店一订阅；多站点多店分别计费。
- 可选：**人工坐席席位**（代运营 / 自有客服接转人工）。

## 档位建议（月付，USD 或等值本币）

| 档位 | 月价（示意） | 含 | 适合 |
|------|--------------|----|------|
| **Trial** | 0（14 天） | 1 店、日消息上限低、水印/额度提示 | 验证 Webhook 与查单 |
| **Starter** | $29–49 / 店 | 1 店、基础自动回复、订单查询、转人工 API | 单店卖家 |
| **Pro** | $79–129 / 店 | 更高消息包、优先队列、多客服席位 1–3、基础报表 | 日咨询量大的店 |
| **Agency** | 面议 | 多店折扣、代运营控制台、专属对接 | 工作室 / 服务商 |

季付约 9 折，年付约 8 折（试点期可更激进）。

## 用量与超额

| 项 | Starter 示意 | Pro 示意 |
|----|--------------|----------|
| 入站消息 / 月 | ~3,000 | ~15,000 |
| LLM 调用（计入消息） | 含在包内 | 含在包内 |
| 超额 | $0.01–0.02 / 条 或升级档位 | 同左，单价略低 |

具体数字以试点 COGS（模型单价 × 平均 token）回算后再锁。

## 不包含 / 加购

- 平台官方广告、备货、仓储  
- 海关 / 税务合规咨询  
- 定制 SOP 与话术库（可按人天）  
- 私有化部署（单独报价）

## 试点策略

1. 前 10 家付费店：Starter 半价或送 1 个月 Pro，换取真实 Webhook 日志与差评话术样本。  
2. Y1 目标 **30–100 付费店**（见商业计划），不以「注册用户数」考核销售。  
3. 发票与合同：早期可手工；系统内计费可后置。
